EchoLib is a small TypeScript library for managing positional audio in browser-based games. After using it internally for over a year, it was open sourced in August 2025.

It covers the 80% case: 2D positional sound with distance falloff, simple priority queuing, and pause/resume that actually works when the tab loses focus. It is not trying to be a complete Web Audio API wrapper.

The docs are sparse but the examples are good. Contributions welcome, though it will be maintained slowly.
